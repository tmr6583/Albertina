MCP-Supabase

MCP local em Python para o Supabase/PostgreSQL da Albertina. Foi desenhado para gastar poucos tokens, devolver JSON compacto e permitir acesso completo ao banco.

Ferramentas

  • ping: testa a conexao.
  • ls: lista objetos do banco.
  • cols: lista colunas.
  • sql: executa SQL completo.

Instalacao

pip install -r c:\GitHubLocal\Albertina\mcp\MCP-Supabase\requirements.txt

Execucao

python c:\GitHubLocal\Albertina\mcp\MCP-Supabase\server.py

Arquivos

  • server.py: servidor MCP.
  • .env: configuracao local.
  • portable.mcp.json: configuracao portavel para outras IAs.
  • trae.mcp.json: configuracao pronta para Trae.
  • install-trae.ps1: script para registrar no Trae.

Trae

powershell -ExecutionPolicy Bypass -File c:\GitHubLocal\Albertina\mcp\MCP-Supabase\install-trae.ps1
